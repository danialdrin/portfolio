This document outlines a legitimate, high-authority backlink and audience acquisition strategy for **Dani Aldrin** (UI/UX Designer & Frontend Developer).

## 1. High-Authority Personal Developer Profiles (Instant Domain Authority)

Link your production portfolio (`https://danialdrin.github.io/portfolio/` or custom domain) directly from high-DR developer platforms:

### A. GitHub Profile README
- **Action**: Add your portfolio canonical URL to your main GitHub profile ([@danialdrin](https://github.com/danialdrin)) website field and inside the `danialdrin/danialdrin` Special Repository README.
- **Anchor Text**: `Dani Aldrin — Personal Portfolio & Case Studies`
- **Impact**: Domain Authority 96 link + instant indexation by GitHub crawlers.

### B. LinkedIn Profile & Featured Section
- **Action**: Add your portfolio URL to your LinkedIn profile intro (`Contact Info -> Website`) and pin your key projects (**Digital Skill Passport**, **HireSync**, **AI Study Buddy**) to your **Featured Section**.
- **Impact**: High trust signal for recruiters and direct referral traffic.

### C. Developer & Design Community Profiles
- **LeetCode**: Add portfolio URL to your user profile ([dani-aldrin-m13](https://leetcode.com/u/dani-aldrin-m13/)).
- **HackerRank**: Add portfolio URL to your profile ([danialdrin_d](https://www.hackerrank.com/profile/danialdrin_d)).
- **Dribbble / Behance**: Create a UI/UX designer profile featuring your Figma/UI mockups linking back to project case study URLs.

### A. DEV.to & Hashnode Case Study Articles
Write 3 targeted technical articles based on your actual projects:
1. *"How I reduced YouTube Data API quota by 45% using a two-stage LLM analysis pipeline"* (Case study on **Digital Skill Passport**).

3. *"Design System Engineering: Material 3 Wealth & Ledger Dashboard in React"* (Case study on **FinTech Dashboard**).

**Backlink Rule**: Embed canonical links back to your portfolio in the article intro and footer:
> *"Originally published on [Dani Aldrin's Developer Portfolio](https://danialdrin.github.io/portfolio/)."*

### B. Medium / Analytics Vidhya
Publish AI/Python tutorials referencing your GitHub repositories and portfolio.

- **NEVER** place hidden links or keyword-stuffed anchor text.
